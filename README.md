# BUTTA-GIUSTO-
Il progetto ButtaGiusto è un progetto open source che mira a semplificare la vita di chi vuole smaltire correttamente i propri rifiuti.  Il funzionamento è completamente deterministico: il sistema utilizza un dataset predefinito e non si avvale di intelligenza artificiale per classificare gli oggetti. Sentiti libero di modificare ed eventualmente migliorare questo progetto , se pensi di aver aggiunto una miglioria , contatta il developer in modo che revisioni la tua modifica ed eventualmente scelga di postarla , il progetto lo trovate su https://buttagiusto.netlify.app/guida
